# Switching-and-Routing-Techniques-Assignment
README

1. Design an appropriate IP addressing scheme (use private IP address ranges).
2. Assign IP addresses to hosts, routers, and switches (SVI or interfaces).
3. Configure host PCs with their IP addresses, subnet masks and default gateways.
4. Configure initial settings on all routers (hostname, banners, passwords, interface descriptions).
5. Assign IP addresses to router interfaces.
6. Configure routing using Static, RIP, OSPF, or EIGRP
7. Configure Router-on-a-Stick inter-VLAN routing.
8. Configure basic switch settings: hostname, passwords, banners.
9. Configure SVI (Switch Virtual Interfaces) with IP addresses for management.
10. Enable and configure SSH access for secure remote management.
11. Configure VLANs (at least 4): name them and assign VLAN numbers.
12. Assign VLANs to specific switchports as access ports.
13. Configure trunking on inter-switch links using 802.1Q encapsulation
14. Configure EtherChannel using PAgP.
15. Configure VLAN routing using a Layer 3 switch.
