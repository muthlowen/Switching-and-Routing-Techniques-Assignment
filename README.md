# Switching-and-Routing-Techniques-Assignment
README

 Design an appropriate IP addressing scheme (use private IP address ranges). 
 Assign IP addresses to hosts, routers, and switches (SVI or interfaces). 
 Configure host PCs with their IP addresses, subnet masks and default gateways. 
 Configure initial settings on all routers (hostname, banners, passwords, interface descriptions). 
 Assign IP addresses to router interfaces. 
 Configure routing using Static, RIP, OSPF, or EIGRP 
 Configure Router-on-a-Stick inter-VLAN routing. 
 Configure basic switch settings: hostname, passwords, banners. 
 Configure SVI (Switch Virtual Interfaces) with IP addresses for management. 
 Enable and configure SSH access for secure remote management. 
 Configure VLANs (at least 4): name them and assign VLAN numbers. 
 Assign VLANs to specific switchports as access ports. 
 Configure trunking on inter-switch links using 802.1Q encapsulation 
 Configure EtherChannel using PAgP. 
 Configure VLAN routing using a Layer 3 switch.
